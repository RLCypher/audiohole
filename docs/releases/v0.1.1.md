AudioHole v0.1.1 improves license readability and adds manual update checks.

- The complete license agreement is readable in light and dark modes in setup,
  portable Release and Debug builds. Formatting and license wording are preserved.
- Settings → About/Update includes **Check for updates**. It checks immediately,
  including when automatic checks are off. If nothing newer is available, it shows
  “Sorry boss, nothing new yet.” with an **Ok** button that closes the popup.
- About/Update includes a link to report bugs and other issues on GitHub.
- Setup uses the AudioHole logo instead of the stock wizard artwork.

Updates preserve profiles, configurations and settings. Installer, portable,
Debug and matching source downloads are provided separately, with SHA-256
checksums and release metadata.

These builds remain unsigned while Microsoft identity verification is pending.
Windows may show an unknown-publisher or SmartScreen warning. Disabling antivirus
is not required.
