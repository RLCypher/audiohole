AudioHole connects Windows audio devices through saved routing profiles and organizes application output assignments with Plug Board.

## Downloads

- **AudioHole Installer:** Windows x64 installer, with optional desktop and Start menu shortcuts.
- **AudioHole Portable:** Extract the ZIP and run `AudioHole.exe`.
- **AudioHole ZIP-debug:** Debug build for troubleshooting.
- **AudioHole ZIP-source:** Matching source code, build instructions and pinned dependency sources.

The installer is a standalone `.exe`. Portable downloads contain no installer or source code. Each filename includes v0.1 and the seven-character source commit. `SHA256SUMS.txt` and `release-info.json` identify the downloads and their integrity checksums.

## Included

- Profiles with independent forward and return audio paths.
- Device scanning, format recommendations and editable JSON configuration.
- Plug Board sockets, application grouping, renaming and inactive-list controls.
- Guided tutorial, user manual, quick-start guide and separate advanced buffer tuning guide.
- Light, dark and system appearance, tray controls and optional personalities.
- Optional weekly update checks against this repository's published releases.

## Unsigned build

AudioHole v0.1 is currently unsigned while Microsoft identity verification is pending. Windows may display an unknown-publisher or SmartScreen warning. Signed builds are planned once verification is complete. Disabling antivirus is not required.
