AudioHole

Put your audio wherever you want.

AudioHole is a Windows audio routing application designed to make managing audio connections simple and flexible.

Features

AudioHole

Device-agnostic audio forwarding allows you to establish audio connections between capture and playback devices, regardless of manufacturer or device type.

Plug Board

An application audio routing configurator that lets you organize applications and assign their audio to your preferred playback devices.

Getting Started

AudioHole is designed to be portable. Simply extract the downloaded archive into a directory of your choice and run the application. No installation is required.

If you prefer a traditional installation, an installer is also included in the download.

An interactive guided tutorial is provided to help you get started, along with a full user manual for additional guidance, and a manual buffer tuning guide for advanced configuration.
