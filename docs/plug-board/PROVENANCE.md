# Provenance and licensing status

The module is original AI-assisted C++ developed to the owner's instructions.
The host project's existing [AI disclosure](Reference/AI_DISCLOSURE.md) and
[engineering standards](Reference/ENGINEERING.md) are copied here unchanged.
EarTrumpet informed architecture/private-ABI research; its implementation was
not copied. The research note is under `Source/docs/plug-board/`.

All 119 original source files and the approved runtime executable retain their
release hashes. `ORIGINAL-RELEASES.json` identifies the accepted ZIPs and base
repository commit. The source is an uncommitted isolated module snapshot; this
handover does not imply a commit, host merge or stable external plugin ABI.

Third-party notices and original Material SVG hashes are preserved in
`Windows/licenses/` and the source assets. Source dependencies retain the exact
CMake pins recorded in `Build/dependency-pins.json`. The AudioHole branding icon
is the unchanged project asset.

The host repository's README explicitly leaves its first-party license to be
selected before public release; the exact section is retained in
[PROJECT_LICENSE_STATUS.txt](Reference/PROJECT_LICENSE_STATUS.txt). This handover
does not choose that license or authorize public publication. The existing owner
license/distribution decision remains a release-administration item; it does not
block this requested internal source/build handover.
