# Contributing to AudioHole

Small, focused contributions are welcome. Open an issue to discuss substantial
behavior or architecture changes before implementing them. Read [AGENTS.md](AGENTS.md)
and the engineering standards linked there. Preserve portable JSON configuration,
explicit device identity, accessibility and real-time audio safety.

Run the relevant checks in [BUILDING.md](BUILDING.md), describe what you verified,
and disclose hardware or platform limitations. Include tests for behavior changes.
AI-assisted contributions are welcome; contributors remain responsible for review,
correctness, provenance and the rights to submit their work. See the AI disclosure
linked from the README.

## License and sign-off

First-party code contributions are accepted under **GPL-3.0-only**, the same license
as the project. Do not submit code with incompatible terms. Retain third-party
copyright and license notices, and identify new dependencies and their licenses.
Asset submissions require an explicit statement of rights and terms; the code
license does not automatically settle artwork licensing.

Every commit must include a Developer Certificate of Origin sign-off:

```text
Signed-off-by: Your Name <your-email@example.com>
```

Use `git commit -s`. By signing off you certify the statements in [DCO](DCO).
The sign-off is a provenance certification, not copyright assignment or permission
to relicense your contribution under arbitrary terms. There is no separate CLA.
Do not add another person's sign-off without their authorization.
